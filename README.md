# Mahantesh S Nigudgi — Portfolio

Personal portfolio website for **Mahantesh S Nigudgi** — Python Developer & AI/ML enthusiast.

## Live Preview

Open `index.html` in a browser or run:

```bash
python -m http.server 8080
```

Visit `http://localhost:8080`

## Deploy to GitHub Pages

```bash
git add .
git commit -m "Personal portfolio — Mahantesh S Nigudgi"
git remote add origin https://github.com/mahantesh-nigudgi/portfolio.git
git push -u origin main
```

Then: **Settings → Pages → Source: `main` branch, `/ (root)`**

## Customize

- Replace initials avatar with a photo in the About section
- Add project GitHub links when repos are ready
- Set up [Formspree](https://formspree.io) for the contact form
